# Library Management System (Java)

A simple library manager that uses Java Collections and File Handling to store and retrieve book data.

## Features
- Add, view, and save books  
- Data persistence using file serialization  
- Uses ArrayList to store books  

## How to Run
1. Open in any IDE  
2. Run `LibraryManagementSystem.java`  
3. Books will be saved automatically to a local file (`library.dat`)

## Technologies Used
- Java  
- Collections (ArrayList)  
- File Handling (Serialization)

## What I Learned
- Reading/writing objects to files  
- Using serialization for data storage
